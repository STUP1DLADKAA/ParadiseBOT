# On-device speech-to-text for the spoken wake word.
#
#     pip install -r requirements-local-stt.txt
#
# Everything in this file runs on the bot's own CPU, in its own process: no
# API key, no account, no audio ever leaving the machine. The rest of the bot
# works without it; with it installed, `VOICE_WAKE_STT=local` makes the wake
# word 100% local.
#
# The model weights are not in here — the first utterance downloads the size
# chosen by VOICE_WAKE_STT_MODEL (75 MB for `small`) into the Hugging Face
# cache, once. See docs/voice-wake.md.
-r requirements.txt

# CTranslate2 build of Whisper + its runtime. Includes ctranslate2, tokenizers,
# huggingface-hub, onnxruntime and av; roughly 250 MB installed.
faster-whisper>=1.1,<2.0
