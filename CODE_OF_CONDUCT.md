# Code of conduct

## The short version

Be decent. Assume good faith. Remember that this is a bot for a friend group
and a repository maintained in someone's spare time.

## Expected behaviour

* Critique code, not people. "This blocks the event loop" beats "this is bad".
* Assume the other person knows something you don't — then ask.
* Respect a maintainer's decision to keep the scope small. Paradise
  deliberately has no dashboard, moderation suite or music player.
* Keep issues on topic and pull requests focused.

## Unacceptable behaviour

* Harassment, insults, or discriminatory language of any kind.
* Publishing someone's private information without permission.
* Sexual attention or imagery in a project space.
* Deliberately derailing issues or pull requests.
* Using the project to record or redistribute other people's voice without
  their consent. The bot's voice-clip features are operator-gated for exactly
  this reason.

## Scope

This applies to issues, pull requests, discussions, commit messages and any
space where someone is representing the project.

## Enforcement

Maintainers may edit, remove or reject contributions and comments that violate
this document, and may block accounts for repeated or severe violations.
Reports can be sent privately via
[GitHub Security](https://github.com/STUP1DLADKAA/ParadiseBOT/security/advisories/new)
if you would rather not raise them publicly.
